
# House Price Prediction Using Linear Regression

## Internship
Oasis Infobyte — Data Analytics

## Task
Level 2 — Task 1

## Objective
To analyze housing data and build a machine learning model
that predicts house prices using Linear Regression.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Project Workflow
1. Load and inspect the dataset.
2. Check missing values and duplicate records.
3. Perform exploratory data analysis.
4. Detect potential outliers using IQR.
5. Encode categorical features and handle missing values.
6. Split data into training and testing sets.
7. Train a Linear Regression model.
8. Evaluate the model using MSE, RMSE, MAE and R².
9. Visualize actual vs predicted prices and residuals.
10. Analyze model coefficients.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python house_price_prediction.py
```

Add the actual MSE, RMSE, MAE and R² values from your terminal.
