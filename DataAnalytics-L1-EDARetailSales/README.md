
# Task 1: Exploratory Data Analysis on Retail Sales

## Objective
Analyze retail sales data to discover sales trends, customer behavior,
product performance, and actionable business insights.

## Technologies
- Python 3.10
- pandas and NumPy
- Matplotlib and Seaborn

## Project Structure
- main.py: Runs EDA and generates visualizations.
- inspect_data.py: Inspects the dataset and generates quality reports.
- retail_sales.csv: Input dataset.
- outputs/: Saved reports and charts.
- screenshots/: Screenshots of project execution.

## How to Run
1. Install the required libraries.
2. Place retail_sales.csv in this directory.
3. Run `python inspect_data.py`.
4. Run `python main.py`.
5. Review the outputs folder.

## Analyses
- Dataset structure and data quality
- Mean, median, mode and standard deviation
- Monthly and quarterly sales trends
- Customer age and gender distributions
- Top products and category revenue
- Numerical correlation heatmap
- Sales by weekday
