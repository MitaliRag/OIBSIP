# OIBSIP Level 2 Analytics Dashboard

An interactive Streamlit dashboard combining four Data Analytics projects.

## Projects
1. Android App Market Analysis
2. Fraud Detection
3. House Price Prediction
4. Wine Quality Prediction

## Technologies
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn

## Installation
python -m pip install streamlit pandas plotly scikit-learn openpyxl

## Run Dashboard
python -m streamlit run combined_level2_dashboard.py

Note: The original credit card dataset is excluded because it exceeds GitHub's individual file size limit.
