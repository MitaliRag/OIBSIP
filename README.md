\# OASIS INFOBYTE – Data Analytics Internship Projects



Welcome to my \*\*OASIS INFOBYTE Data Analytics Internship Projects\*\* repository! This repository contains my projects focused on data analysis, data cleaning, customer segmentation, and sentiment analysis using Python.



\## 📌 Projects



\### 1. Exploratory Data Analysis (EDA) – Retail Sales

\- Explored retail sales data using Python and Pandas.

\- Analyzed revenue, product categories, sales trends, and customer demographics.

\- Created visualizations to identify useful business insights.



\*\*Tools:\*\* Python, Pandas, NumPy, Matplotlib, Seaborn



\### 2. Customer Segmentation

\- Analyzed customer purchasing behavior.

\- Used RFM (Recency, Frequency, Monetary) analysis to understand customer value.

\- Applied clustering techniques to identify customer segments.

\- Created charts and segment-level reports to support marketing decisions.



\*\*Tools:\*\* Python, Pandas, Scikit-learn, Matplotlib, Seaborn



\### 3. Data Cleaning

\- Checked data quality, missing values, duplicates, and potential outliers.

\- Prepared a cleaned dataset for further analysis.

\- Generated data-quality reports and visualizations.



\*\*Tools:\*\* Python, Pandas, NumPy, Matplotlib, Seaborn



\### 4. Sentiment Analysis – IMDb Reviews

\- Analyzed positive and negative movie reviews.

\- Converted text into numerical features using TF-IDF.

\- Compared Multinomial Naive Bayes and Logistic Regression models.

\- Evaluated performance using classification reports and confusion matrices.

\- Generated sentiment distribution charts and word clouds.



\*\*Tools:\*\* Python, Pandas, NLTK, Scikit-learn, Matplotlib, WordCloud
