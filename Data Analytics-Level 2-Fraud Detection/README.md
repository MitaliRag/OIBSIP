# Credit Card Fraud Detection

## OASIS INFOBYTE — Data Analytics Level 2, Task 3

### Objective
To analyze credit card transactions and identify potentially fraudulent transactions using machine learning.

### Dataset
Credit Card Fraud Detection dataset containing transaction features and a binary fraud label.

### Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Logistic Regression
- Random Forest Classifier

### Project Workflow
1. Load and inspect transaction data.
2. Check and clean missing and duplicate records.
3. Explore fraud distribution and transaction amounts.
4. Split the dataset into training and testing sets.
5. Train Logistic Regression and Random Forest models.
6. Evaluate precision, recall, F1-score, and ROC-AUC.
7. Generate confusion matrices and ROC curves.
8. Export predictions and model comparison results.

### How to Run
Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the program:

```bash
python fraud_detection.py
```
