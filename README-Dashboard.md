# OIBSIP Level 1 Analytics Dashboard

An interactive dashboard combining four Data Analytics projects.

## Projects
1. Data Cleaning
2. Customer Segmentation
3. EDA Retail Sales
4. Sentiment Analysis

## Technologies
- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn

## Install Dependencies
python -m pip install streamlit pandas plotly scikit-learn openpyxl

## Run Dashboard
python -m streamlit run combined_dashboard.py
