
# Android App Market Analysis

## Internship
OASIS INFOBYTE - Data Analytics Level 2, Task 4

## Objective
Analyze Google Play Store apps to understand categories, ratings, installs, pricing, and reviews.

## Dataset
Google Play Store Apps Dataset.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib
- Seaborn

## Workflow
1. Load and inspect the dataset.
2. Clean duplicates and convert numeric columns.
3. Analyze app categories and ratings.
4. Compare free and paid apps.
5. Explore ratings and installation counts.
6. Visualize correlations.
7. Export cleaned data and category summaries.

## How to Run

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the analysis:

```bash
python android_app_analysis.py
```
